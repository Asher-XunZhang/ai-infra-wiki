# 上下文与调用预算

适用于调度 Codex → 本机 Harness；读取状态和判断是否续聊都在本地完成，不向模型发“查询用量”或“汇报进度”请求。模型与 Max 保持用户指定值。

## 会话边界

- 审核完成、进入获批实施，或开始一个新的需求：新会话。新会话读取当前文件和精简检查点，不继承旧聊天全文。
- 相同目标的短返修：完成本地预算检查后才恢复。合并已知缺陷再反馈，避免逐项小问题携带整段历史反复调用。
- 长实施任务：先按共享依赖和可验收结果拆批；每批保留可继续的文件状态。不要将“逐章完成全部页面”变成一个没有交付边界的会话。
- 轮换不意味着回滚文件或丢掉方案。交接保留已批准决策、事实来源、必要约束、实际验证和剩余问题，模板见 [交接包](../assets/handoff-template.md)。

## 旧会话的本地诊断

新实施与返修批次统一使用 [受管后台工具](guarded-jobs.md) 和短检查点；下面的只读脚本用于诊断旧会话，不再把 `PASS` 直接串接裸 CLI 恢复命令。受管启动器创建新会话，并在运行中执行预算。

当前 rc.2 的会话投影位于 Harness 用户数据目录下 `storages/session_projcache/sessions/session-<ID>.json`。按实际安装位置传入；不要搜索或读取凭据。此格式是版本相关的本地观察接口，升级后重新核对，缺字段不能当作零用量。

```sh
# projection_file 由调度方核对；
# cwd 为目标工作区；budget_script 指向本 Skill 的 scripts/check_session_budget.py。
python3 "$budget_script" --projection "$projection_file" --cwd "$PWD"
```

阶段变化时检查加 `--phase-changed`，记录轮换决定后按 runtime 文档启动新会话（不带旧 session ID）。

| 检查结果 / 退出码 | 调度方动作 |
| --- | --- |
| `PASS` / 0 | 仅表示本次快照未超阈值；不代表挂载了运行中钩子。新批次仍用受管工具。 |
| `REVIEW` / 10 | 最近一次输入或记录的压力 ≥ 128,000 tokens；先整理检查点，默认新会话。确有不可拆依赖时才明确说明依据并调整本次参数，不静默跳过。 |
| `ROTATE` / 20 | ≥ 256,000 tokens，或阶段变化；不再恢复旧会话，用检查点开新会话。 |
| `BUSY` / 30 | 投影记录未结束的 turn；先核对 PID/退出状态，不能重复启动。异常退出后的陈旧标记不等于仍运行，确认无写入者后以检查点新开，不改写投影伪造完成。 |
| `UNKNOWN` / 40 | 缺字段、格式变化或 cwd 不符；检查本地记录，不能把未知计为零或绕过检查继续旧会话。 |

128k / 256k 是针对本项目长会话问题设置的初始检查阈值，不是 DeepSeek 官方额度、最佳上下文长度或费用上限。脚本支持 `--warn-tokens` / `--rotate-tokens`；调整须记录任务理由与后续效果，不为通过检查直接抬高阈值。上下文值是上次记录，不是下一次调用的精确 token 预测；缓存输入也计入长度。

## 运行中的收束

以下是调度原则；实际预算注入、检查点退出与宽限上限由 [受管工具](guarded-jobs.md) 执行，不再让 Codex 每隔 30 秒解读同一份进度。工具观察频率不等于模型唤醒频率。

恢复前检查无法限制一次长 turn 内所有调用。调度方观察本地日志/投影，并在交接包明确本批完成条件、进度文件和自然检查点：

- 大约每增加 40 个模型回复，或上下文达到上述预警线，复查实际产出与剩余工作。这是观察频率，不是已实施的服务端硬限额；读取本地记录不产生模型费用。
- 有产出则完成当前最小可验收单元，记录检查点后换会话继续。不要强杀正在写文件或清理浏览器的执行者；异常失控时先核对当前动作，再按已支持的取消机制安全停止。
- 同一个失败、同一组条件连续尝试两次仍没有新证据：先定位环境或前置条件，停止机械重试；保留结果并报告阻断，不能无限循环。
- 为进度轮询不要打断模型，也不要把状态查询发成新 turn。非紧急缺陷先归入待验收清单，完成后一次性反馈。
- 日志、截图和生成产物保留文件引用；输入失败摘要和必要的代表截图。变更后跑相关检查，最后做必要整体回归；不为了缩短上下文取消事实核验或实际看图。

## 压缩和计费边界

保留官方自动压缩兜底，但不依赖它管理预算：摘要本身会调用模型，频繁手动压缩也有成本。本次流程不修改全局压缩配置，不影响其他项目；升级或调参时先查 [官方参数](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/compaction/compaction-basic/README.md)。

本地统计只是已记录的会话用量，不能当成账户结算，也不保证覆盖摘要、重试等额外请求。总量反映重复处理，不是唯一文本长度。检查结束记录：阶段、会话、输入长度、累计输入/输出、验证结果、是否轮换；价格和费用另查平台账单。不要为测试预算工具发付费请求。
