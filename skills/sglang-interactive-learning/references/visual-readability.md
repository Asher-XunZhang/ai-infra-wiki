# 动画布局与过程可读性

用于机制图的布局、重叠遮挡修复及共享画布变更。以下规则来自层级图局部遮挡与整章密度复核，约束阅读结果，不指定所有图的布局、库或固定像素值。

## 从两类修复提炼的结论

| 已发生的问题 | 通用结论 | 完成判据 |
| --- | --- | --- |
| 层级图的移动激活块与层／缓存面板相互覆盖 | 空间预算包含对象本体、标题、内部文字及移动范围；终点留白不等于路径安全 | 起点、中途和终点均能辨认对象及所属层，相关说明不被遮住 |
| 矩阵算式、步骤标题与解释挤在一起 | 机制所需信息齐全之后，还要组织清晰的阅读顺序与信息密度 | 输入、操作依据与结果可以就近对照，读者不必猜先读哪段 |
| 归约的输入、对齐计算和输出标题叠在一起 | 阶段名称与实际内容要对应，各部分需要可区分的空间 | 能分清原始贡献、正在进行的计算和结果归属 |
| 默认画面正常，移动中不同值或身份重合 | 动画占用的是整个运动过程的空间，不能只验收静态布局 | 暂停时关键身份、来源、目标和当前动作仍可追踪 |
| 矮窗口把长图压小，字体补偿又使文字挤出槽位 | 响应式同时受宽度、高度和缩放影响，字体与容器必须协调 | 默认视图可读；窄屏、短窗口与缩放后不靠极小字号或裁切容纳内容 |
| 数值和功能测试通过，用户仍看不懂 | 语义正确、过程可追踪、阅读可理解分别验收 | 能根据图解释结果与等待原因，而不只验证最终数值 |

## 布局与运动的取舍

- 先确定当前要读的关系，再安排标题、图例、固定参照、计算内容与移动对象。辅助说明可渐进展开，当前判断必需的条件、单位和身份保持可见；不强制所有图采用固定分区或三段模板。
- 为完整可见对象留空间，包括长标签、多位数、公式、边框、箭头端点和选中态。SVG 的逻辑坐标、文字实际包围盒及屏幕缩放后的占用不同；单看容器尺寸或 `overflow` 不足以判断遮挡。
- 静态布局检查对象间距，运动检查路径经过的区域。调整布局、路径、对象规模或说明位置，由实际问题决定；只改绘制顺序／`z-index` 常会把被遮挡对象换成另一个，不能作为已经解决的证据。
- 区分讲解顺序与执行依赖：可以逐项解释数学贡献，但不能让读者误以为各 rank 的独立计算或传输必须串行。无依赖动作继续共同推进；若分步聚焦，保留整体并发关系或明确这是推导顺序。不要为避让对象添加概念外的中转站、队列或完成条件。
- 可读性修复不得改变数据语义：身份与来源保持可追踪，复制时保留必要原件；接收数量按实际到达更新，消费者等到全部必要条件满足。不能靠提前显示结果、隐藏必要输入或省略关键转换减少拥挤。
- 处理缩放时同时考虑字、框、行距和画布空间。按内容选择重排、合理高度、局部展开或可发现的平移／缩放入口；这些控件不能替代默认状态的基本可读性。一次修复中的字体补偿系数、画布高度和扫描字号阈值不是跨页面标准，也不是无障碍合格证明。

## 真实浏览器验收

按修改影响选择覆盖，保留案例入口、场景／参数、播放位置、视口宽高、主题及缩放状态，确保问题可重现。

1. **先复现用户看到的状态。** 使用实际页面和完整视口条件；查看整张图，不能只看用户圈出的局部。检查同一布局的长标签、多位数、对象最多等相邻状态。整章任务包含主图与保留的选读实验。
2. **检查轨迹。** 覆盖端点及关键中间态，尤其是路径交叉、对象到达、拆分／合并、说明切换与释放前后。均匀半步扫描只是筛查；缺陷可能出现在四分之一步或事件边界附近。实际操作中途暂停、恢复、倒退、切换条件和重置，不能用强设终态代替播放验证。
3. **检查实际阅读尺寸。** 桌面、窄屏与较矮窗口按受影响范围选取，记录宽和高；例如宽屏短窗口与窄屏长窗口能暴露不同缺陷。查看默认缩放、适配全图及相关缩放／键盘操作，确认文字、公式和身份能直接读出。主题及减少动态效果沿用课程既有验收要求。
4. **分开验收三种结果。** 语义：数值、所有权、依赖与到达条件正确；过程：对象与来源在关键中间态可追踪；理解：看图能指出输入、当前动作、结果依据和下一步条件。前两项通过不能代替第三项，不用测试数量证明易懂。
5. **按影响回归。** 单图修复检查该图及共享调用方；字体补偿、相机、画布高度等共享变更覆盖所有受影响渲染类型，并抽查未重画课程。完成判据满足后复用同版本证据，不无依据地重复整章检查。

## 几何告警怎样判断

包围盒相交、文字越界、字体尺寸和画布裁切适合自动发现候选，不能自动等同可见缺陷。结合透明度、裁切区域、绘制顺序、所属对象及当前教学动作查看截图或现场页面：

- 不同数值互相覆盖、关键身份消失、标题或算式被挡，以及稳定画面的文字不可读，属于应修复的问题。
- 同值副本刚离开原件、到达值覆盖空位占位符、已解释完成的离场对象缩小，可能是合理表现；只有不丢失当前所需信息才可接受。
- 相同文字也可能代表不同身份，不能按字符串相同就一律豁免；被占位框包含也不代表一定没有遮挡。
- 对误报记录可重现状态和可见依据，缩小到对应关系，不关闭整类检查。几何无告警也不证明阅读顺序清楚；仍需实际观察代表画面。

## 回归与交付证据

回归断言应检查读者可观察的结果及必要不变量，例如不同身份仍可辨认、关键文字未被覆盖、数值及就绪条件正确。除非是明确产品契约，不把某个 CSS 类名、固定画布高度或一次选定的坐标当作成功定义。旧测试失败时先核对是否为既有问题或旧选择器，不能删掉有效断言以换取通过。

交付记录说明修复范围、实际检查的场景与视口、代表性中间态、人工复核及未覆盖边界；自动扫描没有发现问题，不写成所有可能帧都无缺陷。浏览器生命周期按 Harness 工作流管理。发布另按用户授权进行，并核对线上页面及版本化资源属于已验证构建。
