组合拓扑：同样四张卡，TP=2 / PP=2 怎样分组？
stage 0 · L1–2
rank 0rank 1
同级 TP 组 [0,1]
stage 1 · L3–4
rank 2rank 3
同级 TP 组 [2,3]

跨级沿相同 TP 坐标组成 PP 组：0 → 2、1 → 3。每个 rank 只保存本级层的本地 TP 分片。rank 是进程身份，group 是参与一次通信的成员集合。

这个模型并行世界有 TP × PP = 4 个 rank。EP、Attention DP、CP 可以在已有 TP 世界内再分组，不能把所有参数再相乘成卡数。核对分组实现 ↗

先预测，再操作

TP 两张卡都输出两个数，是否已经算完？

切到 Row。局部贡献 [3,5] 与 [7,25] 的形状相同，但需要逐位置相加才能得到 [10,30]。看见 shape 一样不能代替检查元素语义。

PP 有两张卡，为什么第一格仍有一张空闲？

后级依赖前级的激活。切换 1 个与 3 个 microbatch，观察填充与排空：多批次可以重叠不同层的工作，但无法消除同一批次的先后依赖。

普通 DP 和 EP 都在分任务，为什么不能互换？

DP 在实例入口选择请求副本；EP 在 MoE 层处理 token 与专家的配对。一次请求可以产生很多 token，每个 token 又可以选择多个专家。

上下文各切一半，工作量与 KV 占用一定各减半吗？

CP 的连续对照仍是四个查询对四个查询，却有 10 / 26 对因果可见关系。Zigzag 将这一项变为 18 / 18；所选路径还会汇合当前 K/V，所以两种“减半”都不能只凭查询个数推断。
