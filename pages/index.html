第一章 · 推理基础

先把文字变成向量，再沿一次 Transformer 前向追到下一 token。接着拆开 Attention，看看生成怎样一轮轮接续，最后理解历史状态为什么值得缓存。

  1. 01Tokenization 与 Embedding：文字怎样变成模型输入？能把一句话的文字片段、词表编号和输入向量对应起来。
  2. 02Transformer 前向总览：从输入向量到下一 token能沿架构图从输入向量追到候选分数，理解 Attention、归一化、残差和 FFN 分别改变什么。
  3. 03Attention 与 Q/K/V：模型怎样参考上下文？能说明 Q、K、V 各自参与哪一步、未来位置为什么被挡住，以及同一个 Query 在两个头中怎样得到不同结果并合并。
  4. 04自回归生成：Prefill 与 Decode 怎样接续？能追踪同一个 token 从被选出、送回模型到写入各层 K/V，并说明 Prefill 与 Decode 的区别。
  5. 05KV Cache 与前缀复用：为什么保存历史 K/V？能区分模型权重、历史 K/V、请求映射和可复用前缀。
  6. 06Batch 调度：动态组批、连续批处理与 Chunked Prefill能区分等候组批与轮次间补位，并解释等待上限、整批结束和空位各自控制什么。
  7. 07GPU 计算与访存：算力、带宽和 CUDA Graph能说明算力、带宽与执行提交分别影响哪一段。
  8. 08TP、PP、DP、EP、SP 与 PCP/DCP：多卡怎样分工？能区分七类并行的切分对象、通信载荷与适用场景，并解释 PCP / DCP 的成本。
  9. 09通信语义：Broadcast、Reduce、AllToAll、Send/Recv 与同步能够根据所需输出选择通信语义，并说明参与者、载荷、顺序与完成条件。
  10. 10PD Disaggregation：Prefill 与 Decode 为什么分离？能区分 PD 角色分离与 PP 模型切层，并指出交接成本。
  11. 11Speculative Decoding：草稿候选怎样验证和接受？能解释连续接受前缀，以及错误候选之后的状态为何不能直接保留。
  12. 12请求路由与取消：服务在线为何还没收到回答？能区分健康探测、接纳、执行、客户端可见和安全收尾。
  13. 13TTFT、ITL、TPOT 与吞吐：怎样衡量推理性能？能指出首输出等待、后续间隔、总体完成和百分位的测量边界。
