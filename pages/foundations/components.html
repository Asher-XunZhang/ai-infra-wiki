Transformer 基础部件：一层内部怎样计算？

一层里最容易混淆的不是公式，而是每个部件解决什么问题：谁让位置进入比较，谁把整体放大的输入收回可控尺度，谁保留已有表示，谁只做逐位置调制。沿一次前向看它们怎样分工。

可单步操作原理与实现分开来源与教学边界

先看：Attention 与 Q/K/V：模型怎样参考上下文？

先看一层内部的主线，再分别观察位置旋转、尺度调整、残差、门控和头共享改变了什么。

先想清楚：这一课解决什么问题？

Token 进入模型后，同一层要同时解决几件不同的事：位置怎样进入 Q·K 比较，输入整体放大后怎样把尺度收回来，多个 Q 头怎样在保留查询视角的同时少存历史 K/V，已有表示怎样接住子层更新，MLP 又怎样只在每个位置内做连续调制。先分清用途，再看公式和数值，才不容易把对象画错。

同样的内容，怎样让位置影响 Q/K 的比较？

原位置：Q 与 K 有一个相对角度；整体平移：两者共同旋转，夹角保持

旁路保留输入，子层产生增量，两路按对应维度相加。

逐位置的特征变换，门控多做了什么？

普通 MLP：一条特征变换路径；SwiGLU：两条投影分支相乘

两种结构都处理每个位置的特征；SwiGLU 额外用一条分支逐元素调节另一条分支。

MHA：每个 Q 头一套 K/V；GQA：组内共用 K/V；MQA：所有 Q 头共用 K/V

共享的是历史 K/V；每个 Q 头仍独立查询并产生自己的输出。

01

位置和尺度：为什么先改变 Q/K 与输入幅度？

Attention 比较 Q 与 K。仅比较未带位置信息的固定 Q/K 时，移动它们的位置不会改变点积；RoPE 按位置旋转 Q、K 的成对维度，让相对位置进入点积比较，但不保证不同位置必得不同分数。核对：q=k=[1,0]、θ=π/4，pQ=1、pK=0 得 √2/2；两者同时 +3 仍得 √2/2；pQ=3、pK=1 的相对角为 90°，点积为 0。真实模型各维频率可不同，本课只展示一对。

RMSNorm 处理输入整体放大后的尺度问题：r=√(mean(x²)+ε)，y_i=γ_i·x_i/r；不减均值。x=[3,4]、ε=1e−6 时 r≈3.535534，x/r≈[0.848528,1.131371]；γ=[1,2] 后≈[0.848528,2.262742]。输入整体放大为 2x 时 r 也放大，归一化把两者收回同一尺度；只乘同一标量时方向保持，经过不同 γ 后不保证方向不变，也不能把柱子画成等高。

02

4 个 Q 头为什么能共享 K/V？

生成时历史 K/V 会被反复读取；若每个 Q 头都保存一份历史，存储随 Q 头数增长。Q 头仍需要不同查询视角，所以保留 4 个独立 Q，只减少独立 K/V 组数：MHA 4 组，Q_i 读 KV_i；GQA 2 组，Q0、Q1 读 KV0，Q2、Q3 读 KV1；MQA 1 组，所有 Q 读 KV0。减少的是历史 K/V 副本，不是 Q 头。

该层 K+V 标量数 = 2×3×2×KV 组数 = 48/24/12。它只是这一层的保存量，不是模型全部显存，也不是性能加速比。各头输出还要 concat 后做 output projection；本图没有展开独立头权重与 concat 的数值，不能据此声称任意改训练后头数无损。

03

残差和 SwiGLU 各改变什么？

残差解决“更新怎样接回已有表示”：原输入 x 沿主路保留，子层给出同形更新 F(x)，在加法处逐元素相加。x=[1,2]、F=[0.5,−1] 得 y=[1.5,1]；F=[0,0] 时 y=x。结果形状与 x 相同；拼接会得到 4 维，那不是残差。

SwiGLU 解决“同一位置内怎样连续调制特征”：从同一个 x 得到 g=xWg 与 u=xWu；a=SiLU(g)，z=a⊙u，y=zWd。SiLU 是 g·sigmoid(g)，可以取负、也可以大于 1，不是 0–1 选择开关，也不是专家路由。本课主例 Wg=[[1,1],[1,−1]]、Wu=[[0,1],[1,1]]、Wd=I，x=[1,2]，所以 g=[3,−1]、u=[2,3]；a≈[2.857722,−0.268941]，z≈[5.715444,−0.806824]。

同一组输入的两个局部运算

  1. 残差：1+0.5=1.5，2+(−1)=1，结果仍是 2 维。
  2. SwiGLU：x=[1,2] 经 Wg 得 g=[3,−1]，经 Wu 得 u=[2,3]；SiLU(g)≈[2.857722,−0.268941]；逐元素乘得 z≈[5.715444,−0.806824]。
  3. Wd=I 时 y=z；真实 FFN 的扩展维和回投维度另算。

数值是独立手算例，不是模型权重或 GPU 观测；主例与动画使用同一组权重。

依据：SwiGLU 论文 · Vaswani 等 · Attention Is All You Need

04

拼回一层时，怎样不混淆对象身份？

本课固定 Pre-Norm：x → Norm → Attention → +x 得 x₁；x₁ → Norm → MLP → +x₁ 得 y。分工是：Attention 跨位置汇合历史，MLP 只在每个位置内加工；第一个旁路保留 x，第二个旁路保留 x₁。第二个旁路若画成最初的 x，就会把对象身份弄错。

完整层只交代连接：RoPE 与头分组发生在 Attention 内，SwiGLU MLP 逐位置变换。点击图中的归一化、Attention 标签或残差行可回到对应小演示，再回看这一层怎样把它们接起来。

试着解释

如果把第二个残差画成 y=x+MLP(Norm(x₁))，错在哪里？

展开解释

第二个子层的输入已经是 x₁；旁路必须保留 x₁，才能得到 y=x₁+MLP(Norm(x₁))。画成再加最初的 x 会改变对象身份和结果。

术语速查

RoPE
把位置写成 Q、K 的旋转角，让点积同时包含内容与相对位置；不是给词向量贴位置编号。
RMSNorm
按向量整体均方根缩放，使输入整体放大后仍回到可控尺度；不减均值，γ 再逐维调整比例。
残差连接
保留已有表示作为主路，把子层给出的同形更新逐元素加上去；不是拼接，也不是用更新替换原表示。
SwiGLU
用 SiLU 产生可正可负、可大于 1 的连续系数，对同一位置的另一支投影逐元素调制；不是 0/1 路由或概率。
MHA / GQA / MQA
固定 4 个 Q 头，用 4/2/1 组 K/V 承担历史读取；GQA 保留各 Q 投影，只把 K/V 投影按组共享。共享减少历史存储，但每个 Q 仍独立查询。
Pre-Norm
子层先归一化再计算，输出再加回该子层输入；第二个旁路保留 x₁，不是最初的 x。

对照算例，回看机制与取舍

位置与尺度头共享残差与 MLP拼回一层

位置与尺度：让关系可比较，让幅度可控

Attention 要比较 Q 与 K。仅比较未带位置信息的固定 Q/K 时，移动它们的位置不会改变点积；RoPE 用位置角分别旋转 Q、K 的成对维度，让相对位置进入点积比较，但不保证不同位置必得不同分数。核对：q=k=[1,0]、θ=π/4，pQ=1、pK=0 时点积为 √2/2；两者同时 +3 仍为 √2/2，说明共同平移不改变比较；pQ=3、pK=1 的相对角为 90°，点积为 0。真实模型各维频率可不同，本课只展示一对。RMSNorm 处理另一个问题：输入整体放大后，若不做尺度控制，后续数值会随整体幅度漂移。它先算 r=√(mean(x²)+ε)，再逐维乘 γ；不减均值。x=[3,4]、ε=1e−6 时 r≈3.535534，x/r≈[0.848528,1.131371]；γ=[1,2] 后≈[0.848528,2.262742]。输入 2x 时 r 同步放大，归一化把两者收回同一尺度；只乘同一标量时方向保持，经过不同 γ 后不保证方向不变，也不能把柱子画成等高。

头共享：固定 Q，减少历史 K/V 的保存

生成时历史 K/V 会被反复读取，为每个 Q 头分别保存历史 K/V 会占用存储，且随上下文长度增长；但 Q 头仍需要不同查询视角。于是保留 4 个 Q 头，只改独立 K/V 组数：MHA 4 组，Q_i 读 KV_i；GQA 2 组，Q0、Q1 读 KV0，Q2、Q3 读 KV1；MQA 1 组，4 个 Q 都读 KV0。共享减少的是历史 K/V 副本，不是 Q 头数：各 Q 的投影都保留，GQA/MQA 只把 K/V 投影按组共享。该层 K+V 标量数 = 2×历史×每头维度×KV 组数；历史 3、每头 2 维时为 48/24/12。这只是该层保存量，不是整模型显存，也不是带宽或加速比。各头输出仍需 concat 与 output projection；本图只核对组数、映射和元素数，不声称把已训练 MHA 改成共享组数后输出或质量不变。 六组 Attention 变体的缓存表示、窗口、稀疏选择与递推状态对照，见第 03 课变体主入口；本课保留原头共享动画，不把它扩展成所有模型的统一结构。

残差与 MLP：保留已有表示，再做逐位置调制

残差解决“更新怎样接回原表示”：x 沿主路原样通过，子层只给出同形更新 F(x)，在加法处逐元素汇合。x=[1,2]、F=[0.5,−1] 得 y=[1.5,1]；F=[0,0] 时 y=x。若画成拼接会得到 4 维，那不是残差；若用更新替换 x，已有表示就丢了。SwiGLU 解决“同一位置内怎样连续调制特征”：同一输入 x 做两个投影 g=xWg、u=xWu；a=SiLU(g)=g·sigmoid(g)，z=a⊙u，y=zWd。本课主例固定 Wg=[[1,1],[1,−1]]、Wu=[[0,1],[1,1]]、Wd=I，x=[1,2]，所以 g=[3,−1]、u=[2,3]；a≈[2.857722,−0.268941]，z≈[5.715444,−0.806824]。a 可负、可大于 1，不是 0/1 开关或专家路由；Wd=I 只是教学简化，真实 FFN 还会把扩展维回投到模型宽度。

拼回一层：分工与对象边界

本课固定 Pre-Norm：x → RMSNorm → Attention → +x 得 x₁；x₁ → RMSNorm → SwiGLU MLP → +x₁ 得 y。这里的分工是：Attention 跨位置汇合历史，MLP 只在每个位置内加工；第一个旁路保留 x，第二个旁路保留 x₁，两个身份不能混。一层是一次前向中的一段，不等于生成一个 token；层号、序列位置和 token 是不同对象。点击图中的归一化、Attention 标签或残差行，可回到对应小演示，再回看它们怎样接成一层。

第二个残差 y=x₁+MLP(Norm(x₁)) 中，旁路保留的是最初的 x 还是更新后的 x₁？

自测与解释：第二个残差 y=x₁+MLP(Norm(x₁)) 中，旁路保留的是最初的 x 还是更新后的 x₁？

第一个残差得到 x₁；第二个子层的输入是 Norm(x₁)，旁路也应保留 x₁。拼接或再次加原 x 都会把对象身份弄错。
