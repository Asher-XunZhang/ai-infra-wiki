文字与公式：Embedding 怎样得到初始向量？

编号决定取哪一行，权重决定这一行是什么

Embedding 为每个输入位置按 ID 取一行向量。查表的含义见第 01 课的 Embedding 算例。下面用这行向量作为前向的起点。

xt=E[idt]E∈ℝNvocab×dX∈ℝT×d

t 是序列里的位置，idt 是该位置的 token 编号。E 有 Nvocab 行，每行 d 个数。按位置依次取出 T 行组成输入矩阵 X。教学词表中「？」的编号是 17，取出的两个数一起成为该位置的初始表示。

E=[17]=[0.2,0.3]

读图时分清两个轴。这个例子有 3 个输入位置，每个位置 2 个分量。Attention 在位置之间汇聚信息，FFN 则改变单个位置内部的分量。后面出现的 2 → 3 → 2 指特征宽度，整个序列仍有 3 个位置。

Transformer 原论文 §3.4 · 词嵌入与输出

用整个向量的幅度作参照

两条方向相同的向量 [3, 4] 和 [30, 40] 送入同一个线性投影，后一条的结果整体是前者的 10 倍（忽略偏置）。在 Attention 之前先做归一化，可以减少这种由输入整体大小带来的差异。

r=∑j=1dxj2d+εhi=γixir
  1. 先测幅度。把各分量平方，取平均，再开根号。平方让正负值都对幅度有贡献，平均让参照考虑分量数，开根号把单位恢复到与输入一致。ε 是很小的正数，防止分母接近零。
  2. 再除以共同尺度。忽略 ε 时，[3, 4] 的均方根约为 3.536，[30, 40] 约为 35.355。各自除以自己的均方根，两者都得到约 [0.849, 1.131]。这一步没有减去均值，而且使用同一个正数缩放各分量，保留向量方向。
  3. 最后逐维调节。γ 是训练学到的权重，推理时对不同输入复用。例如 γ 为 [1, 2] 时，第二维再乘 2，结果变成约 [0.849, 2.263]。除以均方根后，各维共用尺度。再乘不同的 γ 后，模型可以让某一维对后续投影有更大的影响，输出的方向和均方根也可能改变。

图中的「输入整体 ×10」省略了 ε，专门展示整体放大会怎样被共同的分母抵消。末位输入为 [0.2, 0.3]，可以跟着图核对它的分母。

r=0.22+0.322≈0.255

除完后两维约为 0.784 和 1.177，再乘增益得到约 [0.941, 0.941]。采用 Pre-Norm 时，这个 h 供 Attention 使用，旁路上的 x 仍按原样送到残差加法。

带 ε 的写法在全零输入时也有正的分母，输出仍为零。两组同方向的输入只有在 ε 可忽略时才近似得到相同的归一化结果。这里的参照来自同一个位置的 d 个分量，每个位置单独计算。

RMSNorm 原论文 §4 · 分母与逐维增益

先算该关注谁，再决定从那里取多少内容

在这个问题里，末位「？」是我们跟踪的当前位置。它用自己的 Query（Q）与可见位置的 Key（K）比较，再按得到的权重读取各位置的 Value（V）。这让匹配使用的特征与最终传递的内容可以由不同的权重学习。

Q=HWQK=HWKV=HWV

H 是各位置归一化后排成的矩阵。以下先看一个头。每个位置用相同的三组投影参数生成自己的 q、k、v。Q 和 K 需要同宽才能做点积，V 的宽度决定每个位置能提供多少内容分量。撇号标记 RoPE 旋转后的 Q′、K′，打分使用这两组向量。

为什么要用三套投影？

当前位置要寻找的特征、之前的位置用来参与匹配的特征，以及匹配后传过去的内容，承担不同的计算任务。给它们各一套权重，可以独立调整。例如「首都」所在位置的 K 可以使它更容易与问题相关的 Query 匹配，V 则可以同时传递多个特征。交换两个位置的查询与被查询角色，也会换用不同的投影，匹配分数因此可以不同。

S=Q′K′⊤dk+Msij=qi′·kj′dk+Mij

S 的第 i 行第 j 列表示位置 i 读取位置 j 的分数。K 上的转置把每个位置的 Key 变成一列，因此一行 Query 可以和所有 Key 逐个求点积。

逐位置打分
固定一行 Q，逐一与各位置的 K 做点积，也就是对应分量相乘再求和。固定长度时，方向越对齐，点积越大。向量长度也会影响点积，因此模型还需要控制这一组分数的尺度。公式中的 dk 是一个头的 Q/K 向量维度。
挡住未来位置
矩阵 M 是因果掩码。允许读取的位置加 0，未来位置加负无穷。取指数后，未来位置的贡献为 0。若只把未来位置的分数置 0，指数反而是 1，仍会分到权重。例如在教学序列中，「首都」能读「法国」和自身，末位「？」能读三个位置。训练时已有完整序列，因此这个限制也用来阻止当前位置提前看到后面的答案。
形成加权结果
softmax 固定 Query 位置 i，在该行沿 Key 位置 j 归一化。算出的同一个权重乘到对应 V 的每个分量上，再逐分量相加。若两个位置的 V 恰好相同，两者之间怎么分配权重都不会改变这一对的合计贡献，合计多少由它们的权重之和决定。

分数的差距决定权重相差多少

softmax 先对每个分数取指数，再除以指数之和。当两个位置的分数相差 1，前者的权重约是后者的 2.72 倍。相差 8 时，倍率变成约 2,981。两种情况下排第一的是同一个位置，但其余位置参与汇聚的程度差很多。

这就是「集中」在前向中的影响。比如「法国」和「首都」各提供一部分线索，若仅因打分的整体尺度偏大而过早压低第二个位置，它的内容就很少进入结果。输入确实需要集中关注一个位置时，集中的权重也可以是合理结果。

要抵消的是波动幅度，它按平方根增长

原论文用一个简化假设解释尺度的选择。假定 Q 与 K 的各分量相互独立，平均值为 0、方差为 1。每一对分量相乘，乘积仍然平均为 0，方差为 1。把 dk 个独立乘积相加时，正负项可以抵消，平均值仍为 0，但方差会相加。

sraw=q·k=∑i=1dkqikiVar⁡(sraw)=dkStd⁡(sraw)=dk

方差衡量的是平方后的波动，开根号才得到与分数同单位的标准差。因此，维度翻 4 倍时，典型波动只翻 2 倍。除以 √dk，标准差约回到 1。若除以 dk，标准差就继续缩小，有限数量的位置分数变得太接近，softmax 权重也会趋于平均。

Std⁡(srawdk)=1Std⁡(srawdk)=1dk

取 dk = 64。在上述假设下，不缩放、除以 √64、除以 64，标准差分别是 8、1、0.125。正数缩放不改变分数排名，改变的是差距及随后分配的权重。训练后的 Q/K 不一定满足这些独立性假设，因此这是设计动机，并非对每一行实际分数的保证。

与减去最大值分开理解。除以 √dk 改变分数差，能改变权重集中程度。减去最大值是给所有分数减去同一个数，差距和权重都保留，目的是避免直接取指数时溢出。

Transformer 原论文 §3.2.1 与脚注 1

RoPE 让匹配能感知相对位置

先把 Q/K 各取一对分量当作平面向量，再按所在位置旋转。不同位置产生不同转角，旋转保留各向量的长度。Q 与 K 都向同一方向额外转相同的角度时，它们的相对夹角保持不变，点积也保持不变。

q′=Rpqk′=Rrkq′·k′=q⊤Rr−pk

p、r 是两个位置，R 是按位置确定的旋转。公式中的 r−p 说明位置以相对差进入比较，实际分数还取决于原始 q、k。RoPE 不负责禁止读取未来，因果掩码仍在打分后单独生效。这张图只旋转 Q 与 K，V 仍用于传递内容。

图中的「？」在位置 2，这一对分量转 1.2 弧度。「法国」在位置 0，K 的向量不转。切到「首都」时，K 在位置 1，转 0.6 弧度，同时换成了「首都」自己的 K。若要单独看位置改了什么，可以用下方固定原向量的 RoPE 对照。实际 RoPE 通常会按成对分量使用不同的旋转频率，图里只演示一对。

多头各自汇聚，输出投影再混合

每个头用自己的投影得到一组匹配结果和权重。一个头的权重覆盖的是它看到的位置，多个头各自归一化。图中两个头分别输出 2 维，按头顺序拼成 4 维，再乘 WO 得到能与残差相加的 2 维更新 ΔA。

ΔA=Concat⁡(head1,…,headn)WOWO∈ℝn·dv×d

n 是头数，dv 是每个头的输出宽度。把两个头的结果拼接只是按顺序排在一起。乘 WO 才会跨头混合。图中输出第一维使用的四个系数是 1、0、0.3、0.1，因此两个头都有分量参与计算。若只把两头逐维平均，就会固定同维等权相加。学习到的 WO 则可以为每个输出分量选择不同组合。

Transformer 原论文 §3.2 · 注意力与多头 · RoFormer 原论文

已有表示走旁路，子层学习如何更新它

子层在归一化后的输入上算出 ΔA，旁路送来归一化之前的 x。两条向量同宽，所以可以逐元素相加。图中的第一个分量把 0.20 加上约 0.74，得到约 0.94。若子层给出零更新，模块便可原样传下既有表示。

x1=x+ΔAx1,i=xi+ΔAi

逐维相加保留了同一宽度，也让子层可以学习较小的增量。负的更新可以抵消输入的一部分，因此「保留」指原向量有一条直接进入加法的路径。

旁路为什么也影响训练？

把输入的第 i 维稍微调大时，加法左边直接把这个变化传到输出，右边的更新也可能随之改变。导数里对应两条路径。第一项的 1 来自旁路，在子层的局部导数很小时仍有直接贡献。总导数还取决于第二项，两项也可能抵消。

∂x1,i∂xi=1+∂ΔAi∂xi

残差学习原论文 §3 · 恒等旁路

Attention 已经改了表示，FFN 需要它自己的归一化输入

第一次 RMSNorm 看到的是 x，第二次看到的是残差相加得到的 x₁。相加可能改动方向和整体幅度，先前对 x 的缩放不能代替对 x₁ 的测量。第二次重新计算均方根。两处 γ 在真实模型里一般分别学习，教学图给它们相同的数值，便于观察分母怎样改变。

h2=RMSNorm⁡(x1)

第一次归一化的均方根约为 0.255。Attention 的更新加到 x 后，新向量约为 [0.944, 0.950]，均方根约为 0.947。若继续除以前一个尺度，两个分量就会都接近 3.7。第二次用当前的均方根重新缩放，再乘增益，得到送给 FFN 的约 [1.196, 0.803]。

归一化后的 h₂ 进入 FFN。第二条旁路从归一化前的 x₁ 分出，直接到后面的加法节点。两条线的起点相同，中间经历的计算不同。

在同一个位置内展开、调节，再组合

d 是层间表示的宽度，m 是 FFN 中间宽度。图里 d 是 2，m 是 3。Attention 可以让「？」读到「法国」和「首都」这样的其他位置，FFN 则只读取当前表示中已有的分量。同一层的 FFN 参数由各位置共享，输入不同就能产生不同结果。

  1. 两路投影各得到 m 个分量。上投影和门控投影各用一组 d × m 的权重。矩阵每一列规定怎样加权组合输入分量，产生一个中间分量。更宽的空间可以容纳更多组合，代价是参数和计算量增加。
  2. 对门控分支做非线性处理，再逐元素相乘。SiLU 把门控分量 g 变成 a，a 的第 j 项再乘 u 的第 j 项。图中第 1 通道的 a 约为 1.498，放大了 u。第 2 通道的 a 约为 −0.248，把正的 u 变成约 −0.079 的 z。门控系数由当前输入算出，因此换一个上下文，同一通道的响应就可能改变。
  3. 用下投影回到 d 维。下投影矩阵有 m 行、d 列。每个输出分量都能从全部中间通道取不同的加权组合。结果是新的 ΔM，宽度与旁路的 x₁ 相同，所以后面可以直接相加。
u=h2Wupg=h2Wgateaj=SiLU⁡(gj)=gj·σ⁡(gj)z=a⊙uΔM=zWdown
SiLU 的系数从哪来？为什么要加非线性？

σ 是 sigmoid。给它一个标量 t，它就给出 0 和 1 之间的数。SiLU 把这个系数乘回 g 本身，最终的 a 可以为负，g 较大时也可以超过 1。逐元素相乘用的是 a，图中的通道因此可能保留负响应、减弱或放大。

σ⁡(t)=11+e−t

普通 FFN 若只连续乘两个线性矩阵，可以先把矩阵相乘，升维和降维合起来仍是一次线性变换。SwiGLU 的逐元素乘积本身就把两路输入特征结合起来，SiLU 则让负、近零和正的门控响应有不同的变化幅度。

一个中间通道怎样影响两个输出分量？

先看上投影矩阵的第 j 列。h₂ 的每一维乘以这一列对应的权重，求和得到 u 的第 j 项。门控得到 z 后，换成按下投影的第 j 行来读。同一个 z 的第 j 项为每个输出分量提供一份贡献。

uj=∑i=1dh2,iWup,ijzj=aj·ujΔMi=∑j=1mzjWdown,ji

图中第 2 通道的下投影权重是 [0.1, −0.5]。它的 z 是负数，所以这一个通道把第一维往下拉，把第二维往上推。再把三个通道的贡献相加，得到 ΔM。

−0.079·[0.1,−0.5]≈[−0.008,0.040]

降维把 m 个中间通道的贡献合成 d 个新的分量。若某个通道的 z 接近 0，它这次的贡献也小。不同通道还能在某一输出维上相互抵消。哪些特征被增强或减弱，由当前激活和下投影权重共同决定。

y=x1+ΔM

图中 ΔM 的第一维约为 1.276，第二维约为 −0.194。加回后，x₁ 的两维从约 [0.944, 0.950] 变为 [2.219, 0.756]。这个例子可以直接看出，一个子层在同一位置既能增强某个分量，也能压低另一个。下一层会在各位置的新向量上重新计算 Q/K/V，因此 FFN 在单个位置做的更新也可能影响后续的跨位置汇聚。

层层更新表示，最终把尺度交给输出头

第 2 层拿到的是第 1 层已经更新过的各位置表示。即使 token ID 没变，本轮各层的 Q、K 和 V 也会从各自的输入生成。后续层可以把前一层形成的特征用到新的匹配和变换，层间仍传递相同宽度的表示。教学模型在不同层复用部分权重，同时改变部分投影的系数，因而能看到表示继续变化。

x(ℓ+1)=Layerℓ+1(x(ℓ))hfinal=FinalNorm⁡(x(N))

括号中的上标是层编号，x(0) 表示送进第 1 层之前的状态，x(N) 是第 N 层输出。一次生成新 token 的前向会走过这些层，层编号与生成轮次是两个不同的计数。

Pre-Norm 子层把计算得到的更新加回旁路，因此最后一次加法后的幅度并未归一化。图中最后一层的第一维约为 7.223，最后一次 RMSNorm 把它调到约 1.681。它仍是 2 维表示。在线性输出头前，若只把整个向量成倍放大，所有分数差也会被成倍放大，概率会更偏向高分候选。最终归一化可以减弱前面累积的整体幅度对打分尺度的影响。

生成下一轮时，已有位置的 K/V 可以从缓存读取。当前新增位置的表示仍需经过各层，逐层生成当前自己的 Q/K/V。想看这个区别怎样影响推理，可以接着读KV Cache。

看完之后，试着解释

把 FFN 的输出加回主流时，旁路保留的是最初的 x，还是第一次残差更新后的 x₁？

旁路保留第一次残差更新后的 x₁。第二次 RMSNorm 和第二条旁路都从同一个 x₁ 出发。前者算出给 FFN 用的输入，旁路则把 x₁ 直接送到加法节点。

一个权重大的位置，会让输出的每一维都变大吗？

同一个权重乘到 V 的各维上。若某一维原本为负，增大这个位置的权重会让这一维的贡献更负。总结果还要把其他位置的贡献加上。看 Attention 动画里「首都」的 V，两个分量对输出的贡献方向正好不同。

如果某个 FFN 通道的门控响应接近零，输出还会有变化吗？

保持上投影值和下投影权重固定时，门控响应越接近零，这条通道给各输出维的贡献就越接近零。其余通道仍按各自的响应贡献，残差还会加上原有的 x₁。可以在 FFN 的「下投影组合」一步检查这些量。

RoPE 对照：Q 和 K 一起移动，点积会变吗？

固定两者旋转前的向量为 [1, 0]，每前进一位旋转 45°。先让两者相距一位，若一起后移三位，相对夹角仍为 45°。若只让它们的距离从一位增加到两位，夹角变为 90°。两条向量的长度始终为 1，点积就是夹角的余弦。

cos⁡(45°)≈0.707cos⁡(90°)=0

这组数只检验固定内容时的位置效果。主图切换观察「法国」和「首都」时，原始 K 也跟着更换，因此不能把两次分数的差全部归因于位置。
