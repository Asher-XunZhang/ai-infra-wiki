Transformer 基础部件：一层内部怎样计算？

沿一次前向拆开 RoPE、RMSNorm、Attention 头共享、残差与 SwiGLU，再拼回 Pre-Norm 层。

可单步操作原理与实现分开来源与教学边界

先看：Attention 与 Q/K/V：模型怎样参考上下文？

上一课看 Attention 怎样汇合上下文；这一课把一层拆成可分别核对的部件。每个小演示只改一个条件，先看输入、运算和结果，再回到完整层看连接关系。

先想清楚：这一课解决什么问题？

Token 进入模型后，一层并不只做一次矩阵乘。位置怎样进入 Q/K，归一化改什么尺度，多个 Q 头怎样共享 K/V，残差加的是谁，SwiGLU 的门控又控制什么？这些对象混在一起时，公式容易对、图却会误导。

01

位置和归一化为什么先改变 Q/K 与尺度？

RoPE 对 Q、K 的每一对维度按各自位置旋转。同一对维度、相同初始向量时，点积由相对位置决定：q=k=[1,0]、θ=π/4，pQ=1、pK=0 得 √2/2；两者同时 +3 仍得 √2/2；pQ=3、pK=1 的相对角为 90°，点积为 0。真实模型各维频率可以不同，本课只展示一对。

RMSNorm 不减均值：r=√(mean(x²)+ε)，y_i=γ_i·x_i/r。x=[3,4]、ε=1e−6 时 r≈3.535534，x/r≈[0.848528,1.131371]；γ=[1,2] 后≈[0.848528,2.262742]。只乘同一标量时方向保持；经过不同 γ 后不保证方向不变，也不能把柱子画成等高。

02

4 个 Q 头为什么能共享 K/V？

固定 4 个 Q 头、3 个历史位置、每头 2 维。MHA 保留 4 组 K/V，Q_i 读 KV_i；GQA 只保留 2 组，Q0、Q1 读 KV0，Q2、Q3 读 KV1；MQA 只保留 1 组，所有 Q 读 KV0。共享减少的是 K/V 组数，Q 头仍各自形成查询并独立加权。

该层 K+V 标量数 = 2×3×2×KV 组数 = 48/24/12。它只是这一层的数量，不是模型全部显存，也不是性能加速比。各头输出还要 concat 后做 output projection；本图没有展开独立头权重与 concat 的数值，不能据此声称任意改训练后头数无损。

03

残差和 SwiGLU 各改变什么？

残差保留原输入，在加法处与子层结果逐元素相加：x=[1,2]、F=[0.5,−1] 得 y=[1.5,1]；F=[0,0] 时 y=x。结果形状与 x 相同，拼接会得到 4 维，那不是残差。

SwiGLU 从同一个 x 得到 g=xWg 与 u=xWu；a=SiLU(g)，z=a⊙u，y=zWd。SiLU 是 g·sigmoid(g)，可以取负，不是 0–1 选择开关，也不是专家路由。g=[1,−1]、u=[2,3] 时 a≈[0.731059,−0.268941]，z≈[1.462117,−0.806824]。本课取 Wd=I 只是教学简化。

同一组输入的两个局部运算

  1. 残差：1+0.5=1.5，2+(−1)=1，结果仍是 2 维。
  2. SwiGLU：g=[1,−1]，u=[2,3]；SiLU(g)≈[0.731059,−0.268941]；逐元素乘得 z≈[1.462117,−0.806824]。
  3. Wd=I 时 y=z；真实 FFN 的扩展维和回投维度另算。

数值是独立手算例，不是模型权重或 GPU 观测。

依据：SwiGLU 论文 · Vaswani 等 · Attention Is All You Need

04

拼回一层时，怎样不混淆对象身份？

本课固定 Pre-Norm：x → Norm → Attention → +x 得 x₁；x₁ → Norm → MLP → +x₁ 得 y。第二个旁路来自 x₁，不是最初的 x；否则读者会误以为又把原 x 加了一次。层号、序列位置和 token 是不同对象，一层也不等于生成一个 token。

完整层只交代连接：RoPE 与头分组发生在 Attention 内，SwiGLU MLP 逐位置变换。点击图中的归一化、Attention 标签或残差行可回到对应小演示，再回看这一层怎样把它们接起来。

Pre-Norm 一层的前向连接
阶段输入运算输出
第一个子层xAttention(RMSNorm(x))与 x 相加得 x₁
第二个子层x₁SwiGLU MLP(RMSNorm(x₁))与 x₁ 相加得 y
后续y进入下一层不是直接生成 token

试着解释

如果把第二个残差画成 y=x+MLP(Norm(x₁))，错在哪里？

展开解释

第二个子层的输入已经是 x₁；旁路必须保留 x₁，才能得到 y=x₁+MLP(Norm(x₁))。画成再加最初的 x 会改变对象身份和结果。

术语速查

RoPE
旋转位置编码：用位置角旋转 Q、K 的成对维度，使点积取决于相对位置。
RMSNorm
按均方根缩放每个向量，再逐维乘 gamma；不减均值。
残差连接
把子层输出与同一形状的原输入逐元素相加，不是拼接。
SwiGLU
用 SiLU 门控一支投影，再与另一支投影逐元素相乘。
MHA / GQA / MQA
4 / 2 / 1 组 K/V 的三种头共享方式；每个 Q 头仍独立查询。
Pre-Norm
每个子层先归一化再计算，子层输出再与原输入相加。

对照算例，回看机制与取舍

位置与归一化Attention 的头残差与 SwiGLU拼回一层

位置与归一化：Attention 前改变了什么？

RoPE 分别用 Q、K 所在位置旋转同一对维度。q=k=[1,0]、θ=π/4 时，pQ=1、pK=0 的点积为 √2/2；两者同时 +3 仍相同，而相对距离变成 2 时点积为 0。真实模型的每个维度对可以使用不同频率，本课只展示一对。RMSNorm 先算 r=√(mean(x²)+ε)，再逐维乘 γ；它不减均值。x=[3,4] 时 r≈3.535534，x/r≈[0.848528,1.131371]，γ=[1,2] 后≈[0.848528,2.262742]。γ 改变比例，因此不能把归一化理解为均值 0 或方向一定不变。

Attention 的头：Q 独立，K/V 可以共享

固定 4 个 Q 头、3 个历史位置、每头 2 维。MHA 用 4 组 K/V；GQA 用 2 组，Q0、Q1 读 KV0，Q2、Q3 读 KV1；MQA 用 1 组，4 个 Q 都读 KV0。每个 Q 仍独立打分和加权，共享的是 K/V。该层 K+V 标量数 = 2×位置数×每头维度×KV 组数，本例为 48/24/12；它只是该层 KV 数量，不是整模型显存。各头输出仍需 concat 与 output projection，不能声称改训练后的组数无损。

残差与 SwiGLU：逐元素相加与逐元素门控

残差把同形状的 x 与 F(x) 逐元素相加：x=[1,2]、F=[0.5,−1] 得 [1.5,1]；F=[0,0] 时 y=x。它不是拼接。SwiGLU 用同一输入做两个投影：g=xWg、u=xWu；a=SiLU(g)=g·sigmoid(g)，z=a⊙u，y=zWd。g=[1,−1]、u=[2,3] 时 a≈[0.731059,−0.268941]，z≈[1.462117,−0.806824]。SiLU 可负，不是 0–1 开关；本课取 Wd=I 以看清乘积，真实 FFN 还会把扩展维回投到模型宽度。

拼回一层：Pre-Norm 与对象边界

本课固定 Pre-Norm：x → RMSNorm → Attention → +x 得 x₁；x₁ → RMSNorm → SwiGLU MLP → +x₁ 得 y。第二个残差加的是 x₁，不是最初的 x。Attention 内含 RoPE 和头分组；MLP 逐位置变换，不混合历史位置。一层是一次前向中的一段，不等于生成一个 token；层号、序列位置和 token 是不同对象。

第二个残差 y=x₁+MLP(Norm(x₁)) 中，旁路保留的是最初的 x 还是更新后的 x₁？

自测与解释：第二个残差 y=x₁+MLP(Norm(x₁)) 中，旁路保留的是最初的 x 还是更新后的 x₁？

第一个残差得到 x₁；第二个子层的输入是 Norm(x₁)，旁路也应保留 x₁。拼接或再次加原 x 都会把对象身份弄错。
