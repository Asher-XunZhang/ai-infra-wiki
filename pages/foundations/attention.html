Attention 与 Q/K/V：模型怎样参考上下文？

从一行向量开始：提出查询、比较相关程度、汇合信息，再继续处理。

可单步操作原理与实现分开来源与教学边界

先看：Tokenization 与 Embedding：文字怎样变成模型输入？ · 自回归生成：Prefill 与 Decode 怎样接续？

知道了向量，下一步才是看模型怎样用上下文。下面每个位置用两个数表示。点击推进，看当前查询如何给允许读取的位置打分，再按权重混合它们携带的数值。

先想清楚：这一课解决什么问题？

“苹果”出现在“吃苹果”和“苹果发布新电脑”里，初始 token 表示本身不足以区分语境。Attention 让当前位置根据当前需要，从允许读取的上下文中组合信息。它计算的是向量关系，不是人工编写的关键词规则。

理解设计：为什么需要这些机制？

为什么不能只看当前 token，或者平均所有位置？为什么要把 Query、Key、Value 分开？遮罩、位置和前馈层为什么仍然需要？
01

为什么不能只看当前 token，或者平均所有位置？

只看当前 token 无法处理指代、语序和远处条件；把所有位置等权平均又容易淹没真正相关的信息。Attention（注意力）让不同位置对当前结果产生不同贡献，并随输入内容改变这些贡献。

以 Transformer 为例，每一层都可以更新这种上下文表示。一个 attention head（注意力头）只提供一组投影与加权路径，多头可学习不同的组合方式；不能事先把某个头固定解释成语法或事实检查器。

依据：Vaswani 等（2017）· Attention Is All You Need

回到问题导航 ↑
02

为什么要把 Query、Key、Value 分开？

Query（查询，Q）表示当前用于匹配的特征，Key（键，K）表示其他位置用于被匹配的特征，Value（值，V）是匹配后要汇入结果的内容。它们通常由输入经过不同的可训练投影得到：判断相关性的特征，与最终携带的信息不必相同。

点积得到匹配分数，缩放后用 Softmax 形成权重，再对 V 加权求和。模型不会因此把被关注的词从原位置取走；输出是多个数值向量的组合。

权重怎样真正影响结果

  1. 假设两个可见位置的 Value 分别为 2 和 8。
  2. 当前 Query 对应的归一化权重若为 0.75、0.25，输出就是 0.75×2 + 0.25×8 = 3.5。
  3. 换一个 Query，权重若变为 0.25、0.75，输出就变为 6.5。

这是独立的一维手算例；主动画使用二维向量展开分数与权重的来源。

依据：动手学深度学习 · 注意力评分与加权

03

遮罩、位置和前馈层为什么仍然需要？

Causal Mask（因果遮罩）排除未来位置，使训练时的并行计算遵守生成时的可见范围。位置机制则向模型提供顺序信息；否则只按内容匹配不能充分表达“谁在前、谁在后”。不同模型可使用不同位置方案。

Attention 负责跨位置组合信息，逐位置的前馈网络负责进一步变换特征，残差连接使层能够在已有表示上添加更新。2017 年 Transformer 用注意力组织序列交互，减少了对循环网络逐位置递推的依赖；这不意味着生成时未知的未来 token 也可以直接并行确定。

试着解释

如果把所有位置的权重固定成相同值，失去了什么能力？

展开解释

仍然能混合 Value，但失去了随当前 Query 和上下文改变各位置贡献的能力。需要相关信息时，它可能被无关内容的平均贡献淹没。

术语速查

Q / K / V
Q 是当前查询，K 用来与查询比较，V 是被混合的信息；都是计算得到的数值，不是三份原文。
Attention
根据 Q 与 K 算出权重，再对 V 加权汇合。这里的权重是一次计算的结果，不等同模型训练参数。
Self / Cross
Self 的 Q、K、V 来自同一序列；Cross 的 Q 与 K/V 来自不同序列。Cross 的可见性要按两个来源各自的时间或对齐规则定义，不能直接套用同序列的 j≤i。
KV 组
同一层保存几套历史 K/V。Q 头数与 KV 组数互相独立：本例 MHA 4Q/4KV、GQA 4Q/2KV、MQA 4Q/1KV。GQA 保留各 Q 投影，只把 K/V 投影按组共享。
MLA
每个位置缓存压缩后的 latent c，并单独保留 RoPE 位置 key；读取时恢复内容 K/V，或把投影吸收到查询/输出路径。它不是 KV 头数变体，缓存仍随位置数增长。
SWA
当前层只让最近 W 个位置（含当前 query）进入 softmax 候选；窗口外历史可能仍在缓存里，不等于已删除或立即回收。
DSA / 主缓存
轻量 indexer 选 Top-K；main cache 保存完整历史主缓存，未选中条目不删除。主缓存可采用 MLA 潜表示等非展开形式，DSA 本身不要求展开的完整 K/V 向量。
NSA
压缩摘要、选中块的原 token、近期窗口三路分别读取并做各自的 softmax，最后用独立门控汇合；门不要求归一化。
递推状态
GDN / KDA 维护固定形状的当前状态并逐位置更新，不保存逐 token K/V 列表；卷积窗口、检查点和投机临时状态是另外的生命周期。

Q/K/V 与 Softmax：从分数到加权结果

算例使用 Q=K=输入向量、V=输入向量的两倍，以免同时引入大矩阵；真实模型用训练得到的投影产生 Q/K/V。动画逐项显示分数、归一化权重和加权和，不把“读取历史”画成直接拿走某个词。

Causal Mask：同序列因果与 Cross 的可见性

同一序列的因果 Self 常按“位置 i 只读 j≤i”组织遮罩；整段输入可以并行计算，但每个 query 只读允许范围。Cross 的两个序列各有自己的时间或对齐定义，不能无条件拿两个数字下标套 j≤i，要按来源规定哪些目标位置可被当前 query 读取。被遮住不等于对应历史被删除或立即回收。

Transformer Layer：一层计算与一次生成的区别

一次 Prefill 或 Decode 都要走完模型需要的各层。主图只展开 Attention 子层；图内的“进入完整层”会带着同一个 Query 走过 x → Norm → Attention → +x → Norm → MLP → +x₁，再回到原来的暂停帧。MLP 与 Attention 是两个独立子层，第二个残差保留的是 x₁；一层不等于生成一个 token。下一课只跟踪其中值得保存的历史 K/V。

多头：同一输入 x 的不同投影，最后怎样合并

另设 2 头、每头 2 维、模型宽度 2 的独立算例，与 Transformer 基础部件课里的 4 Q 头分组图区分（那里比较 KV 组数，不展开独立头权重与 concat）：x=[1,1]，Wq0=[[1,0],[0,0]]、Wq1=[[0,0],[0,1]]，得到 q0=[1,0]、q1=[0,1]。两个可读位置的 K 都取 [[1,0],[0,1]]，两头 V 都取 [[2,0],[0,2]]，只为把差异集中在 Wq；本例两头共用这组教学 K/V。真实 MHA 每头有一组 K/V 投影，GQA/MQA 则保留各 Q 投影、把 K/V 投影按组共享，不能把本图推广成所有模型都每头独立 K/V。除以 √2 后，头 0 权重≈[66.98%,33.02%]，h0≈[1.3395,0.6605]；头 1 权重≈[33.02%,66.98%]，h1≈[0.6605,1.3395]。concat 按 [h0_0,h0_1,h1_0,h1_1] 原样接成 4 维，不是把两个结果相加。教学 Wo=[[.5,0],[0,.5],[.5,0],[0,.5]] 再把 4 维投回 [1,1]；这组 Wo 恰好等于两头同坐标平均，一般 output projection 是学出来的 4×2 矩阵，可混合全部 4 个坐标，不能把 concat 或 Wo 说成固定平均，也不声称多头必然提升性能或正确率。

六组机制：先看各自改了哪一层对象

MHA 每个 Q 头有独立 K/V；GQA、MQA 保留 Q 头，只把 K/V 投影按组共享或全部共享。MLA 改每个位置缓存什么：保存压缩 latent 与单独的位置 key，读取时再恢复内容 K/V。SWA、DSA、NSA 改能读哪些位置：SWA 只看最近窗口，DSA 先让 indexer 选位置，NSA 把压缩摘要、选中块原 token 与近期窗口三路分别读完后汇合。GDN / KDA 把显式历史改成递推状态：旧状态先衰减，再根据新信息纠正写回。它们可以组合，不是一条性能排名。

MLA：每个位置保存更窄的表示

MLA 为每个位置保存压缩 latent 和单独的位置 key；内容 K/V 在读取时由 latent 恢复，或在打分、输出路径中吸收投影。这里的改动是缓存表示，不是把 Q 头合并；历史表示仍随位置数增长，也不是固定长度状态。

SWA / DSA / NSA：窗口、按需选位与三路汇合

SWA 让当前层只读最近窗口；窗口外可能仍在缓存。DSA 由轻量 indexer 在可见位置中选 Top-K，主注意力再读取选中的主缓存条目，未选条目仍保留；主缓存可采用 MLA 潜表示。NSA 则同时读压缩块摘要、选中块展开后的原 token、近期窗口；三路各自 softmax，最后用独立门汇合，门不要求和为 1。

GDN / KDA：历史怎样变成当前状态

GDN / KDA 不再保存逐 token K/V 列表，而维护固定形状的当前状态：旧状态先衰减，新信息用来纠正预测并写回，query 再从状态读出。GDN 做整体衰减，KDA 逐通道衰减；固定当前状态不等于混合模型没有卷积窗口、检查点或其他缓存。

观察第二个位置时，后两个位置虽然已经输入，能参加它的注意力汇合吗？

自测与解释：观察第二个位置时，后两个位置虽然已经输入，能参加它的注意力汇合吗？

切到第二个位置，后两个权重为 0；批量组织计算不取消因果关系。

选读 · 完整模型层与 Prefill / Decode 输入范围

完整模型层：Attention 之后还有什么？

本例采用 Pre-Norm 结构：输入 → 归一化 → Self-Attention → 残差相加 → 归一化 → MLP → 残差相加 → 下一层。上方动画只展开 Attention 子层；图内的“进入完整层”带着同一个 Query 进入层内，再回到原来的暂停帧。这里补齐 Prefill / Decode 的输入范围。

阶段新输入位置每个新 Query 可读取的范围
Prefillp1…p4，一次处理多个位置pᵢ 只能读取 p1…pᵢ 的 K/V
Decodey1，一个新位置已有 prompt 与本位置的 K/V

P 和 D 都走完整的模型层。P 处理一段新位置，D 通常每条请求处理一个新位置。

Decoder-only Transformer：Prefill / Decode 的计算路径

这里以 简化的 decoder-only Transformer 为例。这是通用教学图，不是 DeepSeek-V3 的完整结构；V3 的 MLA 压缩缓存与 MoE 专家选择见第三章。图中的一层包含自注意力（Self-Attention）、前馈网络（MLP），以及归一化和残差连接；这样的层重复很多次。Prefill 与 Decode 都经过这些部分，再由输出头和采样步骤选出新 token。

区别在“这一次送进来多少新位置、能读取哪些历史 KV”，而不在“走模型的哪半边”。如果使用 PP，模型层会分到多个 stage，但一次 P 或 D 前向仍需走过整条流水线。

Causal Mask：批量计算中的可见范围

Prefill 可以在一轮前向中处理多个输入位置，因果遮罩仍规定位置 p2 只能看 p1、p2。Decode 的 y1 已有全部 prompt 作为历史，因此能读这些位置的 KV，也会为自身计算并写入 KV。

“P 常更偏计算、D 常更偏访存”是理解负载的出发点，不是硬件定律。批量大小、上下文长度、模型结构和 kernel 都可能改变瓶颈。

自测 · Decode 是否跳过 MLP，只从 KV 中取答案？

不会。KV 复用历史 attention 的 K/V；当前新位置仍要经过 attention、MLP 等完整模型计算，才得到下一 token 的分数。
