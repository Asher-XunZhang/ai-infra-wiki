从一行向量开始：提出查询、比较相关程度、汇合信息，再继续处理。

为什么这样做？

01

为什么不能只看当前 token，或者平均所有位置？

「吃苹果」和「苹果发布新电脑」可以从同一个「苹果」初始向量开始。当前位置读取到的上下文不同，Attention（注意力）就可以产生不同的更新。简单平均时，重复出现的无关内容也会参与结果，模型很难按当前问题改变各处的贡献。

注意力头是一次独立的投影和汇聚路径。下方先跟一个头的结果，多头对照再说明几路结果如何拼接与投影。

依据：Vaswani 等（2017）· Attention Is All You Need

02

为什么要把 Query、Key、Value 分开？

Query（Q）用于发起这次比较，Key（K）提供各位置的匹配特征，Value（V）提供加权读取的数值。分开投影后，同一个位置可以用一种特征获得较高权重，同时传出另一组内容。

固定查询位置 i，计算它与各位置 j 的分数。dₖ 是一个头的 Q/K 宽度。本课手算省略位置变换，直接用给定的 Q/K。因果遮罩 M 给未来位置加负无穷，使这些位置取指数后为 0。分母对同一行求和。最后用这一行的权重逐个乘 V，再逐维相加。

03

遮罩、位置和前馈层为什么仍然需要？

因果遮罩规定「哪些位置可以读」。位置机制改变「怎样衡量这些位置的关系」。第 2 个位置即使与第 3 个位置匹配得很好，也只能看到自身和前一个位置。位置编码能改变分数，但读不到的位置仍被遮住。

同一个位置的各头结果会先合并。在第 02 课的独立算例中，可以沿这个模块的输出继续走到残差和 FFN。

同序列因果 Self-Attention 中，位置 i 能读自身与前文。Cross-Attention 的 Query 与 Key 来自不同序列，不能直接拿两个序列的下标套用此遮罩，应按任务规定可见范围。遮住一个位置也不表示要删除它的缓存。

Attention 汇聚的向量交给谁？

单头算例的结果是一个位置的加权向量。跟到多头算例可看到各头怎样合并。完整层里的残差与 FFN 由第 02 课的架构图接着展示。

多头：同一输入 x 的不同投影，最后怎样合并

这个算例只改变每个头的 Query 投影，取相同的教学 K/V 来控制变量。两头的加权结果先按顺序拼成 4 维，输出投影再把它变成 2 维。这里的输出投影恰好取两头同坐标的平均，学习得到的一般矩阵可混合所有坐标。

六组机制：先看各自改了哪一层对象

MHA 每个 Q 头有独立 K/V；GQA、MQA 保留 Q 头，只把 K/V 投影按组共享或全部共享。MLA 改每个位置缓存什么：保存压缩 latent 与单独的位置 key，读取时再恢复内容 K/V。SWA、DSA、NSA 改能读哪些位置：SWA 只看最近窗口，DSA 先让 indexer 选位置，NSA 把压缩摘要、选中块原 token 与近期窗口三路分别读完后汇合。GDN / KDA 把显式历史改成递推状态：旧状态先衰减，再根据新信息纠正写回。它们可以组合，不是一条性能排名。

MLA：每个位置保存更窄的表示

MLA 为每个位置保存压缩 latent 和单独的位置 key；内容 K/V 在读取时由 latent 恢复，或在打分、输出路径中吸收投影。这里的改动是缓存表示，不是把 Q 头合并；历史表示仍随位置数增长，也不是固定长度状态。

SWA / DSA / NSA：窗口、按需选位与三路汇合

SWA 让当前层只读最近窗口；窗口外可能仍在缓存。DSA 由轻量 indexer 在可见位置中选 Top-K，主注意力再读取选中的主缓存条目，未选条目仍保留；主缓存可采用 MLA 潜表示。NSA 则同时读压缩块摘要、选中块展开后的原 token、近期窗口；三路各自 softmax，最后用独立门汇合，门不要求和为 1。

GDN / KDA：历史怎样变成当前状态

GDN / KDA 不再保存逐 token K/V 列表，而维护固定形状的当前状态：旧状态先衰减，新信息用来纠正预测并写回，query 再从状态读出。GDN 做整体衰减，KDA 逐通道衰减；固定当前状态不等于混合模型没有卷积窗口、检查点或其他缓存。

Attention 机制与工程实现（结构对照）
组改动的对象读取关系不能推成什么
MHA / GQA / MQA每组 Q 共享几套历史 K/V。4 个 Q 头不变，K/V 组数 4 / 2 / 1；同组 Q 各自用 q 打分、各自输出。不是把 Q 头合并，也不是共享输出。
MLA每个位置缓存什么。每位置存 latent 与独立位置 key；内容 K/V 读时恢复或吸收。不是固定状态，缓存仍随历史增长。
SWA当前层直接读哪些位置。最近 W 个位置（含当前 query）进入本层 softmax。窗口外不等于删除或立即回收。
DSA主注意力本次读哪些位置。indexer 先选 Top-K，主注意力只读选中的主缓存条目。索引分不是最终权重；未选条目仍保留在主缓存。
NSA历史按什么粒度并行读取。摘要、选中块原 token、近期窗口三路独立注意力，再由独立门汇合。不是一路的三种视图；三个门不归一化。
GDN / KDA历史放在哪里。压进固定形状状态：先衰减，再用当前 k、v 的预测误差纠正写回，q 读出。固定形状不等于每 token 零成本；GDN 整体衰减，KDA 按通道衰减。
QSA / CSA / HCA索引路径或主 KV 的序列表示。QSA 压索引并展开选中块；CSA 选择压缩主 KV；HCA 读取全部可见高压缩条目，CSA/HCA 另有近期窗口。压缩索引不等于压缩主 KV；遍历压缩条目不等于读全量原 token。
CSA2跨层复用全局 KV 与位置选择。Full 新建并选位；Reindex 复用记录、重选位置；Reuse 复用记录与已有选择。每层仍计算自己的 Q、SWA 与输出；不是复用前层答案。
FlashAttention / PagedAttention计算与搬运 / KV 的物理存储。前者分块计算并在线归一化；后者通过块表读取非连续的 KV 块。这是工程实现维度，不等于改变模型读取哪些逻辑位置。

术语速查
Q / K / V
Q 是当前查询，K 用来与查询比较，V 是被混合的信息；都是计算得到的数值，不是三份原文。
Attention
根据 Q 与 K 算出权重，再对 V 加权汇合。这里的权重是一次计算的结果，不等同模型训练参数。
Self / Cross
Self 的 Q、K、V 来自同一序列；Cross 的 Q 与 K/V 来自不同序列。Cross 的可见性要按两个来源各自的时间或对齐规则定义，不能直接套用同序列的 j≤i。
KV 组
同一层保存几套历史 K/V。Q 头数与 KV 组数互相独立：本例 MHA 4Q/4KV、GQA 4Q/2KV、MQA 4Q/1KV。GQA 保留各 Q 投影，只把 K/V 投影按组共享。
MLA
每个位置缓存压缩后的 latent c，并单独保留 RoPE 位置 key；读取时恢复内容 K/V，或把投影吸收到查询/输出路径。它不是 KV 头数变体，缓存仍随位置数增长。
SWA
当前层只让最近 W 个位置（含当前 query）进入 softmax 候选；窗口外历史可能仍在缓存里，不等于已删除或立即回收。
DSA / 主缓存
轻量 indexer 选 Top-K；main cache 保存完整历史主缓存，未选中条目不删除。主缓存可采用 MLA 潜表示等非展开形式，DSA 本身不要求展开的完整 K/V 向量。
NSA
压缩摘要、选中块的原 token、近期窗口三路分别读取并做各自的 softmax，最后用独立门控汇合；门不要求归一化。
递推状态
GDN / KDA 维护固定形状的当前状态并逐位置更新，不保存逐 token K/V 列表；卷积窗口、检查点和投机临时状态是另外的生命周期。

看完 Attention 的汇聚结果，可以回到第 02 课的完整前向沿着残差和 FFN 往下走。要比较少读一个位置会发生什么，可以在同一课做屏蔽「法国」的实验。
