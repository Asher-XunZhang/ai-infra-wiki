## 自测与下一步

基础自测：能按推理顺序画出各模块，解释因果掩码和填充掩码的区别，以及 FFN 为什么升维、经过非线性再降维；能指出 MoE 的替换位置，区分总参数与单 token 激活参数。进阶自测：能说明 token 前缀长度为什么不等于合法状态恢复边界，并区分共享状态和请求私有状态。
