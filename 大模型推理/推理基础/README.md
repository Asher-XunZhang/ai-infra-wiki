本文是学习导航，分类与阅读顺序由整理者归纳。技术资料继续保留各自的来源、版本和验证边界；导航不表示已完成运行或性能复现。

## 先修知识

不要求已经读过推理引擎源码。先能区分文本、token 和模型输出即可；不熟悉术语时使用各篇文首速查表。

如果还不熟悉模型本体，先读 [Transformer 架构与推理流程](<../模型架构/Transformer 架构与推理流程学习文档.md>)：按一次推理认识各模块，配合全局图、细节图与 FFN 升降维手算例子，再进入引擎和资源问题。
